# nomess

Keeps AI-written code from turning into a mess: commit-time checks, path-scoped lessons, a generated system map and a design-first workflow for Claude Code. Install: `/plugin install nomess --marketplace penstic123-code/Nomess`. Usage, uninstall and what it reads and writes are in the [repository README](../README.md). Script reference: [`scripts/README.md`](scripts/README.md).
